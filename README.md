# Домашнее задание: Список покупок на React

Проект выполнен в рамках задания по веб-технологиям.

---

## 📌 Выполнение требований задания

1. **React**: Проект реализован с использованием библиотеки React (компонентный подход, хуки `useState`, `useEffect`).
2. **Товары с названием и ценой**: У каждого товара есть `id`, `name` (название) и `price` (цена).
3. **Добавление товаров**: Форма ввода названия и цены с валидацией (нельзя добавить пустую строку или отрицательную/нулевую цену).
4. **Удаление товаров**: Кнопка удаления у каждого товара.
5. **Общая стоимость всех покупок**: Автоматический подсчет и отображение суммы всех товаров с форматированием цен.
6. **Отдельный компонент для элемента списка**: Создан компонент `ShoppingItem` (`src/components/ShoppingItem.jsx`), отвечающий за отображение отдельного товара.
7. **Использование `state` и `props`**:
   - **`state` (состояние)** в `App.jsx`:
     - `items` — массив объектов товаров;
     - `nameInput` и `priceInput` — значения в полях ввода;
     - `errorMessage` — текст ошибки валидации.
   - **`props` (пропсы)**: передаются из `App` в дочерний компонент `ShoppingItem`:
     - `id`, `name`, `price` — данные товара;
     - `onDelete` — функция обратного вызова для удаления конкретного товара.

## 🚀 Способы запуска

### Способ 1: Автономный (без установки Node.js / терминала)
Просто откройте файл `standalone.html` двойным кликом мыши в любом браузере (Chrome, Edge, Firefox, Яндекс.Браузер). В нем подключены React 18 и Babel через CDN.

### Способ 2: Запуск в режиме разработки (Vite Dev Server)
1. Откройте терминал в папке с проектом:
   ```bash
   npm run dev
   ```
2. Перейдите по ссылке (обычно `http://localhost:5173`).

### Способ 3: Сборка и просмотр продакшн-версии
```bash
npm run build
npm run preview
```
или откройте файл `dist/index.html`.
